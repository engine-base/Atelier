# GAP-146: モックスタジオ全画面化 — 入れ子解消 / 実寸プレビュー / 会話の格上げ

## 経営者指摘 (スクリーンショット付き)

1. 「ツールの中に組み込まれてますよ感がすごい。独自のツールですよ的にしたい。
   モック画面の中でさらに枠で囲われているし、サイドバーもあることで狭い
   (戻れる状態は絶対に必要だけど)」
2. 「実際のデザインがちゃんとサイズを持って表示できていない。デスクトップなのに
   スマホくらいの広さでしか見れない」
3. 「チャットもしょぼい。タブのチャットの方がよっぽど優れているのに、
   なんでこんなに下がるの？」

## 対応 (apps/web/app/mocks/s_h01/)

1. **フルスクリーンスタジオ化**: ?mock= で開くビューアを `fixed inset-0 z-[500]`
   の全画面 overlay に — アプリのサイドバー・カード枠・max-width の**外**に出て
   独立ツールとして全面を使う。脱出路は topbar 左端の「← モック一覧」(常設)。
   topbar に タイトル / バージョンピル / 新規タブ / HTML DL / チャットで依頼 を集約。
   (z-[500] は TopBar の z-[100] より上、モバイル nav ダイアログ z-[1000] より下)
2. **実寸プレビュー + 自動フィット** (Figma / Open Design と同じ方式):
   iframe を**デバイス実寸の CSS px** (ワイド 1440 / デスクトップ 1024 / タブレット
   768 / モバイル 320) で描画し、キャンバス実測 (ResizeObserver) に対して
   `transform: scale()` で自動フィット。ズームは「フィット / 100%」切替 + 実測 %
   表示。高さもキャンバスいっぱいまで実寸換算で確保 (幅 × 高さ表示は実値)。
3. **ワンダとの会話を S-E01 チャットと同じ作法に**:
   - バージョン履歴を「自分の指示 (右・primary) → ワンダの応答 (左) +
     **タイムスタンプ**」の吹き出しに
   - 送信直後に指示を**楽観表示** + 「ワンダが作業中… (経過 N 秒)」の実測カウンタ
     (GAP-136 と同じ「実測だけ出す」方針)
   - **Enter 送信 / Shift+Enter 改行** (IME 変換中は送信しない)、新着で自動スクロール
   - パネル幅 300px → 340px、ワンダのアバター付きヘッダ

## 実ブラウザ証跡 (Playwright + 実 API + 実 DB の料金ページ v4)

- `studio-fullscreen.png`: 全画面スタジオ (1680×1000)。左=会話 (v1〜v4 の
  指示/応答 + 時刻)、中央=デスクトップ実寸 1024px を 97% フィット表示、
  右=バージョン履歴 + コメント。
- `studio-wide-fit.png`: ワイド切替 — **実寸 1440px** のまま 69% に自動フィット
  (1440 × 1235 表示 — 「スマホ幅でしか見えない」の解消)。
- 実測ログ: `STUDIO_FULLSCREEN {"position":"fixed","w":1680,"h":1000}` /
  `IFRAME_REAL_SIZE {"attrWidth":"1024","transform":"scale(0.96875)"}` /
  `IFRAME_WIDE {"attrWidth":"1440","transform":"scale(0.688889)"}`。
- 途中で発見・修正した実バグ: アプリ TopBar (z-[100]) がスタジオ (旧 z-50) の
  上に重なっていた → z-[500] へ。スクショで再確認済。
