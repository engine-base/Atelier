# GAP-188 — 利用規約に「各自の Claude 契約が必要」を明記

経営者質問: 「ちゃんと法的にも合法だよね？」

## 直す前の実態 — 実装と規約が乖離していた

確定アーキテクチャ（GAP-134 / GAP-175）では、**AI 実行は利用者自身の PC 上で、
利用者自身が Anthropic 社と契約する Claude を使って走る**。当社は AI の推論そのものを
提供していない。

ところが規約には **その記載が一切無かった**:

- 利用者に Claude 契約が必要であること … 記載なし
- Anthropic 社への料金が利用者負担であること … 記載なし
- 利用者が Anthropic 社の規約を遵守する必要があること … 記載なし
- 枠上限・PC 停止で AI 機能が使えなくなること … 記載なし
- 入力内容が利用者の PC 経由で Anthropic 社へ送られること … 記載なし

規約上は「当社が AI を提供している」ようにしか読めない状態だった。

## 直したこと

### 利用規約に第4条・第5条を新設（新 version）

- **第4条（AI 機能の実行環境とユーザー自身の Claude 契約）**
  - AI 機能はユーザー自身のコンピュータ上で、ユーザーが Anthropic 社と契約する
    Claude を用いて実行される。**当社は AI の推論そのものを提供しない**
  - 有効な Claude 契約の保有と、Anthropic 社の規約遵守が必要
  - **Anthropic 社への料金はユーザー負担**（当社の利用料金に含まれない）
  - 当社は Claude の契約を**代理・再販・仲介しない**
  - Bridge のインストールが必要であること
  - 入力内容がユーザーの PC 上の Claude へ送信されること
- **第5条（AI 機能の可用性の制限）**
  - Claude の内容・品質・可用性・利用枠を当社は保証しない
  - 枠上限 / Bridge 未起動 / PC 停止 では**一時的に利用できない**（画面で明示し実行を保留）
  - Anthropic 社が提供条件を変更・停止した場合の影響

### プライバシーポリシーに第4項を新設

AI 機能の実行にあたり、入力内容がユーザーの PC から Anthropic 社へ送信されること、
当社サーバーは指示の中継と結果の保存を行うこと、を明記。
**「AI 学習デフォルト OFF」は維持**（後退させていない）。

### 申し込む前に見える場所へ（規約の中に埋めない）

サインアップ画面に、同意チェックの**手前**で明示:
> AI 機能のご利用には、お客様ご自身の Claude 契約が必要です

「当社は AI の利用料をいただかない代わりに、Claude の契約と料金はお客様のご負担」
「契約が無い場合も AI を使わない機能（案件・タスク・成果物の管理など）は使える」
まで書き、「契約したのに使えない」を作らない。

### 旧版を消さない

`consents.version` で同意済み版を突き合わせているため、旧版（2026-05-25）は
行として残し `is_current` だけ新版へ移した。
