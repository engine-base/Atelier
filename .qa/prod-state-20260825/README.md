# 本番の実測（2026-08-25）— 画面と API はズレていない

## なぜ測ったか

私は直前に「**画面（Vercel）は main への push で自動デプロイ、API（Fly）は手動停止中**
なので、新しい画面が存在しない API を叩いて壊れているかもしれない」と言った。
これは `deploy.yml` のコメント（"Vercel deploy は Vercel GitHub Integration が
自動実行する"）だけを根拠にした**推測**だったので、本番を直接測って確かめた。

`probe.sh` は**読み取りのみ**。本番にデータを作らない（未認証で叩き、
401/403/422 が返れば「口は在る」、404 なら「無い」と判定する）。

## 結果 — ズレていなかった

**画面も API も 7/18 前後で揃って止まっている。** 私の心配は外れ。

本番の Atelier は「利用者が自分の PC・自分の Claude 契約で動かす」形になる前の姿。

### 画面（Vercel）

- サイドバーが `プロジェクト / AI社員 / チャット / タスク / 工程 / ナレッジ /
  承認待ち / 議事録 / WS設定` = **テンプレート（GAP-154, 8月）が無い旧構成**
- `/robots.txt` が **404**（`app/robots.ts` は GAP-204, 08-21 で追加した）
- 法務ページが**旧ハードコード版**を表示している。現行コードは

→ **Vercel は main を自動追随していない。**（production branch の設定か
Integration の状態かは Vercel 側でしか確認できないが、結果として止まっている）

これは 2026-08-13 の経営者判断「本番公開はまだ行わない」と整合している。
`deploy.yml` の push トリガー無効化と足並みが揃っている状態。

## ただし 1 つ、実際に見えているもの

**法務 3 ページは認証不要なので、URL を知っていれば誰でも読める。**
`/tokushoho` `/terms` `/privacy` `/data-deletion` はいずれも 200 を返す。

そこに出ているのは**旧版**で、次の記述を含む。

| ページ | 出ている内容 | 問題 |
|---|---|---|
| 特商法 | 問い合わせ先 **`info@example.com`** | **ダミーのメールアドレス** |
| 特商法 | 販売事業者 **株式会社 Atelier** / 代表者 **代表取締役** | 法人格・氏名が事実と一致するか要確認 |
| 特商法 | 販売価格「各プランページに表示の通り」 | **プランページは存在しない** |
| 特商法 | 「**年額プランは未使用残月分を返金可**」 | **年額プランは存在しない**（実装は月額 5,000 円のみ） |
| 特商法 | 「返金の詳細はプライバシーポリシー参照」 | 返金条件をプライバシーポリシーに書くのは誤り |
| 利用規約 | **全 4 条**（適用・利用登録・AI 学習・退会） | 免責も料金も解約も知的財産権も無い。現行の正本は 15 条 |
| プライバシーポリシー | **全 5 項** | 越境移転（Anthropic 米国送信）の記載が無い |

**緩和要因**: サイト全体に `<meta name="robots" content="noindex, nofollow">` が
入っているので検索には出ない。到達するには URL を直接知る必要がある。

**それでも**、`info@example.com` と「年額プラン」を公開状態に置いておく理由は無い。
GAP-208 で直した正本は既に手元にあるので、**デプロイすれば消える**。
デプロイしないなら、この 3 ページだけ落とすか、URL を伏せる運用にする。
