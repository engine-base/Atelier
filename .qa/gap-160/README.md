# GAP-160: 全画面レイアウト (サイドバー撤去 + 戻る導線) / 左パネルの作り / ロゴのライン統一

経営者指示 (2026-08-19):
- 「ユーザー側も管理側もテンプレ部分も戻れる状態で、左のサイドバーなくして
   しっかり全画面で見れる状態にして」
- 「プロジェクト内の進行はいい感じ。できればここも戻ることができる状態で
   サイドバーはなくしたい。あと左パネルは右パネルみたいな作りにして。
   チャット部分との境がないしわからないので」
- 「常駐しているヘッダーとサイドバーのアトリエロゴのヘッド部分のラインが
   ずれているので統一して。ロゴ小さくしていいので高さをヘッダーに合わせる感じで」

## 実装 (すべて SaaS クラウド側の UI。費用影響なし)

1. **全画面モード** (`AppShell.hideSidebar` + `TopBar` の戻るリンク)
   - テンプレート (`/templates`) と 進行 (`/chat`) はサイドバーを出さず全画面。
   - 代わりにヘッダー左に **「← プロジェクト一覧へ戻る」/「← プロジェクトへ戻る」**
     を常設 — 迷子にならず必ず戻れる。
2. **運営側も同じ** — `/admin/design-templates` は運営メニューを畳んだ専用ヘッダー
   (「← 運営メニューへ戻る」+ 運営タグ) の全画面。
3. **チャット左パネルを右パネルと同じ作りに** — `aside`(白地 + 右境界線 +
   独立スクロール) にして、中央のチャットとの境目をはっきりさせた。
4. **ロゴのライン統一** — サイドバーのブランド枠を `h-14` にしてヘッダーと
   同じ高さ・同じ位置で境界線が繋がるようにし、ロゴ自体は小さく (h-5/h-6)。
