# GAP-204 — 中身を真似させない（技術で守れるもの／法で守るもの）

## きっかけ

経営者から「**AI があるとデザインや HTML/CSS を真似して作られる。どうにかできないか**」。

## 先に、曲げられない事実

**ブラウザに表示する以上、HTML・CSS・画像は必ず相手の手元に届きます。届いたものは
読めます。「見えるのにコピーできない」は原理的に不可能です。**

右クリック禁止・開発者ツール検知・難読化の強化は、30 秒で回避される一方で
正規の利用者の使い勝手とアクセシビリティだけを確実に落とすので、**やっていません**。

## そこで「守れるもの」と「守れないもの」を分けた

| 中身 | 真似できるか | この GAP でやったこと |
|---|---|---|
| 見た目（色・余白・レイアウト） | **できる** | 諦める。法の側でカバー |
| 画面構成・導線 | **できる** | 同上 |
| **AI 社員のプロンプト** | **させない** | 画面側 JS に混ざっていないことを CI で毎回機械検査 |
| **スキル・テンプレ本文** | **させない** | 同上（DB 層の秘匿は GAP-144 で実施済み） |
| 元の TypeScript ソース | **させない** | 本番ソースマップを配らないことを設定＋成果物の両方で検査 |

## ① 流出検査（Gate #16）

`scripts/ci/check-client-leak.py`

- プロンプトを書いている Python **12 ファイル**から、日本語を含む長い文字列を
  **自動で抜き出す**（一覧を手で書かないので、プロンプトを直しても腐らない）
- **一文ごとにも見張る** — Python は隣り合う文字列リテラルを 1 つに繋げるため、
  全文だけを探すと「一部だけ抜き取られた漏洩」を見逃す（**実 e2e で踏んだ**）
- ビルド後の画面側 JS（`.next/static`）に含まれていないか探す。
  バンドラが `\uXXXX` に逃がしても検知する
- 本番ソースマップが配られていないことも同時に見る
- 意図的に共有している文言（利用者向けエラー文など）は理由つきの許可リスト。
  **使われなくなった許可はエラーになる**ので、惰性で膨らまない

### 初回の実行結果（正直に）

709 件の文言を検査して、**プロンプト本文の流出は 0 件**でした。
検知されたのは利用者向けの文言 7 件だけで、いずれも画面にも出す前提のもの
（汎用エラー文、生成物の但し書き、定期実行の費用説明）。理由つきで許可済み。

## ② 検査が本当に効くことの実測（`e2e-output.log`）

「PASS した」だけでは意味がありません（何も見ていなくても PASS します）。
そこで **本物のプロンプト文を画面側のビルド成果物へ実際に埋め込み**、
検査が落ちることを確かめました。

```
[2] 本物のプロンプト文を埋め込む → 検知して落ちた（文言と出どころも報告に出る）
[3] \uXXXX に逃がして埋め込む   → それでも検知した
[4] ソースマップを置く          → 検知して落ちた
[5] 後片付け                    → 元どおり PASS
```

**このとき [2][3] が最初は素通りしました。** 原因は上に書いた「Python が文字列を
繋げてしまう」件で、検査の穴でした。e2e が無ければ「動いているつもりの検査」を
出荷していたところです。

## ③ 法で守る側

技術で止められない分、**誰の著作物で、どういう条件で使えるのかを明示**しました。

- **利用規約 第9条（知的財産権）** — 複製・翻案・リバースエンジニアリング・
  競合サービスへの利用の禁止、**機械学習の学習データとしての利用の禁止**
- **第10条（本サービスの秘密情報）** — プロンプト・スキル・テンプレの様式
- **過剰な主張はしない** — 第9条3項で「**ユーザー自身が作った成果物の権利は
  ユーザーに帰属する**」と明記（囲い込みと誤解されないように）
- 配る HTML に `copyright` と利用条件の所在（`/terms`）を明記
- `robots.txt` で学習用クローラ 15 種を名指しで全面拒否。**規約 第9条4項と対**

> ⚠️ **規約本文は法務レビュー前のドラフト**です（GAP-188 と同じ扱い）。
> 確定文言は法務レビュー後に新 version 行で差し替えます。旧版は残すので
> 同意記録は壊れません。

## robots.txt の限界（正直に）

**強制力はありません。** 無視するクローラは無視します。これは技術的な防御では
なく「**拒否の意思を明示した記録**」で、後から争うときの根拠になるものです。

## どこで動くか / 誰の費用か

検査は CI（GitHub Actions）の中だけ。リポジトリは public なので**追加費用 0 円**。
利用者の PC にも本番サーバーにも影響しません。

## まだやっていないこと（正直に）

- **見た目の模倣は止められません**（原理的に不可能）。ここは規約と、
  実際に模倣が起きたときの対応で戦う領域です。
- 検査対象は **プロンプトを書いている 12 ファイル**。新しくプロンプトを持つ
  モジュールを足したら `SERVER_ONLY_SOURCES` に追加が要ります（追加漏れは
  検知できません）。ファイルが消えた場合はエラーになります。
- **英語のみのプロンプト**は検知対象外です（日本語を含む文字列だけを見ています）。
- 類似サイトの発見（監視）は入っていません。
