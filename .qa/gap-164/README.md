# GAP-164: 「学習に使われません」と「いいものは自動でナレッジ」の整合

経営者の疑問 (2026-08-19):
「チャット部分に学習に使われませんと書いているけど、いいものは自動でナレッジ的に
 する状況にしていなかったっけ？？ここら辺がわかっていないけど」

## まず事実 (混乱の原因はこちらの実装漏れ)

3 つの別々の話が混ざっていました。実装状況も揃っていませんでした。

| 話 | 中身 | それまでの状態 |
|---|---|---|
| A. 外部のモデル学習 | 会話を AI モデルの学習に渡すか | **渡さない** (鉄則: AI 学習デフォルト OFF)。チャットの「学習に使われません」はこれ |
| B. 自社ナレッジ | 会話から得たノウハウを自社の資産として貯める | **未実装だった** ← 経営者の記憶とのズレの正体 |
| C. 全アカウント共有 | 他社にも役立つ知見を匿名化して全体へ | GAP-153 で実装済 (運営の承認が必要)。ただし**入口 (B) が無いので実質空回り**だった |

## 実装 (B を追加し、A/B/C を画面上でも区別)

- `services/knowledge/auto_capture.py`: 応答完了後の非同期処理で、直近の会話から
  **他の案件でも使える形に一般化できるノウハウだけ**を抽出し、そのワークスペースの
  ナレッジ (`account_type=workspace` / `scope=common` / `source_type=ai_extracted`) に残す。
  - 抽出は**本人のサブスク経路**で走る (運営費用ではない)。
  - プロンプトで **社名・人名・金額・URL・日付など案件固有の事実の持ち出しを禁止**。
  - **該当が無ければ何も作らない**。壊れた応答・短すぎる本文は採用しない。
  - 同じ題のナレッジが既にあれば作らない (重複で埋めない)。
  - 失敗しても会話は止めない (次の機会に回る)。
- チャットの表示を実態に合わせた:
  **「外部の学習には使いません · 社内ナレッジには残ります」**
  (ホバーで「一般化できるノウハウはワークスペースのナレッジに自動で残り、
  ナレッジ画面で確認・削除できます」と補足)。
- これで C (全アカウント共有) は B で貯まったものを運営が匿名化+承認して広げる、
  という一本の流れになります。
