# GAP-163: Excel / スプレッドシートの表示と編集、PDF の表示 (と編集の線引き)

経営者質問 (2026-08-19):
- 「あとエクセルとかだとここの表示はどうなるの？？」
- 「エクセルとかスプレッドシートをここで修正とかできるの？PDF もだけど」

**それまでの実態**: Excel はダウンロードしかできず、画面では中身が見えませんでした。

## 実装 (正直な線引き)

| 形式 | 表示 | 編集 |
|---|---|---|
| Excel (.xlsx) / CSV | **表として表示** (シート切替つき) | **セルを直接編集 → 新しい版として保存** |
| PDF | ブラウザ内蔵ビューアで**表示** (inline 配信) | **できない**。理由と代替 (元の成果物を AI に直してもらって出し直す) を画面に出す |
| 画像・その他 | 既存の配信のまま | 表として扱えない旨を返す |

- 編集は **新バージョン**として積む (元の版は残る = 履歴不滅の原則を維持)。
- 保存は元と同じ xlsx 形式なので、**そのままクライアントに渡せる**。
- **数式・書式・グラフは保持しない** (値のみ)。これは画面と API の両方に明記して、
  黙って落とさない。
- `artifact_files` は authenticated から revoke 済のため、**行の認可は RLS**、
  **実体は service 経路** (mock_contents と同じ方式) に分離した。

## 証拠 (実 HTTP / 実ブラウザ)

`curl-evidence.txt` — 実 xlsx (見積明細) と実 PDF (契約書ドラフト) で実測:

```
1) GET /outputs/{id}/sheet → {"file_name":"見積明細.xlsx","editable":true,
   "sheets":[{"name":"明細","rows":[["項目","数量","単価","金額"],
   ["要件定義","1","300000","300000"],["実装","2","600000","1200000"]]}],
   "note":"値のみを表示・編集します (数式・書式・グラフは保持されません)"}
2) POST /outputs/{id}/sheet (単価を 350000 に変更 + 保守行を追加) → 新バージョン作成
3) 新版: [... ['要件定義','1','350000','350000'], ..., ['保守','12','50000','600000']]
   元版: [... ['要件定義','1','300000','300000'] ...]      ← 元は変わらない
4) 保存版を content-url からダウンロード → 200 (…spreadsheetml.sheet)
   openpyxl で開けて シート ['明細'] / 編集後の行がそのまま入っている
5) PDF: GET …/sheet → 409「PDF はこの画面で表示できますが、直接の編集はできません。
   修正は元の成果物を AI に直してもらってから出し直してください」
   表示は 200 application/pdf / content-disposition: inline
```

実ブラウザ:
```
SHEET_PANEL: 1   NOTE: 値のみを表示・編集します (数式・書式・グラフは保持されません)
CELL_BEFORE: 300000 → 保存 → URL が新版へ → CELL_AFTER: 999000
PDF_REFUSAL_SHOWN: 1   PDF_IFRAME: 1
```

- `163-sheet-saved.png` — セル編集 → 新版として保存された状態
- `163-pdf-view.png` — PDF は表示され、編集不可の理由が出ている
