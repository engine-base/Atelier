# GAP-208 — 法務文書を条文に照らして直す + やめる口を作る

## きっかけ

経営者判断（2026-08-22）:

- 「**規約は弁護士には頼まない。あなたで完璧にしてほしい**」
- 「**通知は入らない。画面にエラー的な文章が出るならそれでいい**」

## ⚠️ 先に限界を書く

**私は弁護士ではないため、「法的に完璧」は保証できない。** ここでやったのは
条文（消費者契約法・特定商取引法・個人情報保護法）に照らした点検と是正であり、
法的助言ではない。**直した論点は 19 件のテストで固定**したので、将来また
抜け落ちることは機械的に防げる。

## 見つけた穴と、直し方

### ① やめる口が製品に無かった（法務文書より重い）

**Pro を契約できるのに、解約する手段がアプリのどこにも無かった。**
申し込む口（checkout）だけがあり、`billing` の endpoint は 4 本とも
「契約する・状態を見る・webhook を受ける」で、**やめる経路が存在しなかった**。
継続課金として特定商取引法の観点でも成立しない。

- `POST /billing/portal` を新設 → **Stripe カスタマーポータル**の URL を発行
  （解約・支払方法の変更・領収書の取得。当社は決済情報を持たない）
- 画面は **Pro のときだけ**「プランの管理・解約」を出す（無料プランに死にボタンを置かない）
- 契約が無いのに叩かれたら 409 で正直に断る／Stripe 未設定は 503（理由つき）

### ② 免責条項が、消費者相手だと無効になり得た

旧 第7条: 「**故意または重過失による場合を除き責任を負いません**」
→ 軽過失について **全部免責**。消費者契約法 8 条により無効と判断されやすい典型で、
**無効になると免責が丸ごと消える**（一番まずい状態）。

新 第9条:
- 軽過失のときは **12 か月間の実支払額を上限**とする一部制限へ
- **故意・重過失には制限を適用しない**ことを明記
- 特別損害・逸失利益の除外も軽過失に限定

### ③ 料金・支払い・解約の条項が丸ごと無かった

Stripe で課金する実装があるのに、規約には金額も自動更新も解約も書いていなかった
（第6条＝データ、の次がいきなり免責）。

- 第6条（料金および支払い）: **月額 5,000 円（税込）/ ワークスペース**、
  自動更新、決済代行、**Anthropic 料金は含まれない**
- 第7条（解約）: 設定画面から手続き、**期間末まで利用可・日割り返金なし**、
  アカウント削除は **30 日の猶予**
- 金額と猶予日数は **実装の定数と一致するかをテストが見る**（規約だけ古くなるのを防ぐ）

### ④ 越境移転の記載が弱かった

入力内容は Anthropic（米国）へ送られ、決済は Stripe（米国）を通る。
旧ポリシーは「送信されます」と書くだけだった。

新 5 項: **提供先・所在国・目的を表で明示**（Anthropic PBC / Stripe / Fly.io /
Vercel = すべてアメリカ合衆国）、当該国の制度に関する情報の確認方法、
講じている措置の提供に応じること。委託先（6 項）・保有期間（8 項）・
安全管理措置（9 項）・開示等の請求（10 項）・Cookie（11 項）も新設。

### ⑤ 特商法表記が 3 か月前のまま取り残されていた

「販売価格: 料金ページに表示する金額」と書いてあるが、**公開の料金ページは無い**。

- 実額（月額 5,000 円 税込）を直接記載
- **解約の方法**（画面のボタン名と一致）
- 動作環境（Bridge / 対応 OS / Claude 契約が必要）
- Anthropic 料金がユーザー負担であること

### ⑥ 足りていなかった条項

未成年（法定代理人の同意）・反社会的勢力の排除・利用停止と解除・
**準拠法と専属的合意管轄**を新設。全 15 条になった。

### ⑦ 混雑が画面から見えなかった（通知を入れない判断の帰結）

S-T01 の「同時チャット」行は **その要求を処理した machine のプロセス内カウンタ**で、
2 台目で起きた混雑は映らない。通知を入れないなら、**画面が唯一の気づく場所**になる。

→ 「**混雑の実績（machine 横断）**」の行を追加。直近 7 日を `capacity_events` から
集計し、お断りが出ていれば `err`、待たせただけなら `warn`。
