# GAP-162: 成果物をクライアントに渡す — 共有リンク + 書き出し (HTML / Excel / PDF)

経営者質問 (2026-08-19):
- 「あとは PDF や資料、エクセル、html など様々で出せる感じだよね？？」
- 「これをこのままリンクとして資料を渡せる状態にもなっている？？」

**それまでの実態: どちらも「いいえ」でした** (署名 URL は社内閲覧用で認証必須、
書き出しは無し)。今回そのまま渡せる状態にしました。

## 実装

### 共有リンク (クライアントはログイン不要)
- `POST /outputs/{id}/share-links` で **期限つき** リンクを発行。
- **トークンは DB にハッシュのみ保存** — 一覧では URL を返さない (漏洩時に
  DB からリンクを復元できない)。発行直後の画面でだけ URL が見える。
- `GET /share/{token}` は **認証不要**。成果物のデザイン (テンプレ適用済み) を
  そのまま表示し、上部に「PDF で保存 / 印刷」を出す (印刷時はバーが消える)。
- いつでも失効でき、失効・期限切れは **410** で正直に断る。閲覧回数も記録。

### 書き出し
| 形式 | 実装 |
|---|---|
| HTML | 実体をそのままダウンロード (`?format=html`) |
| Excel | HTML 内の表を xlsx へ決定的変換 (`?format=xlsx`)。見積・請求・タスク一覧など**表が主役の成果物**向け |
| PDF | 共有ページ/プレビューの「PDF で保存 / 印刷」= ブラウザ印刷。A4 前提のデザインテンプレをそのまま PDF にできる |

**表が無い成果物の Excel は 409 で断る** (空ファイルを出さない)。
PDF はサーバー側レンダリングを使っていません — デザインテンプレの CSS を
最も忠実に出せるのがブラウザ印刷であり、レイアウト崩れの偽 PDF を作らないためです。
