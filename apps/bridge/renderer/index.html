あなたの PC で、あなたの Claude プランを使って Atelier の AI 実行を担当します。 このアプリを入れておくだけで、チャットの応答・PC 操作がこの PC 上で動きます。

Claude Code CLI のインストール

確認中…

ターミナルで次を実行してください（WSL や特別な環境は不要です）: 
curl -fsSL https://claude.ai/install.sh | bash
PowerShell で次を実行してください（WSL は不要・Windows ネイティブで動きます）: 
irm https://claude.ai/install.ps1 | iex
PC 操作（コマンド実行）を使う場合は Git for Windows も入れてください（Claude Code の Bash ツールが使用します）。
ターミナルで次を実行してください: 
curl -fsSL https://claude.ai/install.sh | bash
2

Claude アカウントにログイン

確認中…

ターミナル（Windows は PowerShell）で次を実行し、ブラウザでログインしてください。 あなたの Claude サブスクプランがそのまま使われます（Atelier 側に追加料金はありません）: 
claude auth login
3

Atelier と接続

確認中…

Atelier をブラウザで開き、設定 → Bridge 接続 → 「アプリで接続」 を押してください。 このアプリが自動で接続設定を受け取ります（この操作は初回の 1 回だけです）。
