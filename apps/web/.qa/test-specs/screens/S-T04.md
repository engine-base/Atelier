  メール送信。**メール未設定環境は dry_run=true を応答で明示** (偽装しない)。
  audit `support.contact` (subject/to_email/dry_run) に記録。不在 404 / 非 admin 403

  (display_name 解決 + 相対時刻)。送信すると即時反映 (invalidate)
- **UI**: 一覧のサポート列に行ごとの「サポート連絡」→ 件名/本文ダイアログ →
  送信 → 結果バナー (dry-run 明示)。「最近のサポート対応」カード (モック準拠、
  0 件は誠実な空表示)
