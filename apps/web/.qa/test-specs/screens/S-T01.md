**設計根拠 (誠実表示)**: モックのダミー業務数値 (100 社獲得/¥906/99.97% 等) をそのまま
表示せず、**表示値の出所を 3 種に限定**した: ① 実カウント/実計測 (WS 数・30 日実増分・
タスク実行数・DB latency・Bridge presence) ② **運営が明示的に記録した値** (獲得目標・
取得チャネル・コスト — 記録フォーム付き、未記録は honest 空表示) ③ 実設定状態
(外部 API キーの設定有無)。推測の稼働率・創作の売上は表示しない。MRR は課金未導入の
実額 ¥0 と明示。ミッションの「必要ペース」は目標と実数からの実計算。
