# INVITE 招待リンクの受け取り 画面別テスト仕様（/invite/<token>・GAP-315）

> 未登録・未サインインの人が **最初に開く画面**。ここが行き止まりだと、招待そのものが成立しない。
> URL の `<token>` は変数なので、画面の名前は `invite`。
