# IMPORT 既存資料の取り込み 画面別テスト仕様（/import・GAP-156・human-grade-qa test-plan）

> 種別: upload+review / 結果列は空=planned。
> 備考の `ai_required` は実行場所の分離: `no`=この環境で消化する / `yes`=AI 実行基盤が要る（BLOCKED 可）。
> **意図**: 進行中の既存プロジェクトを**途中から**ツールに載せる。手元の HTML/MD/画像/PPTX 等をまとめて
> 取り込み、モック・成果物へ仕分け、完了済み工程を提案して、**ユーザーが確定するまで勝手に進めない**。
> 取り込みは相手の実物を扱うので、**失敗したファイルを黙って捨てない**ことが最重要。
