### 検出・是正した欠陥

| # | 欠陥 | 分類 | 是正 |
|---|---|---|---|
| 1 | **死に入力 3 件: クライアント表示名・有効期限・スコープが「黙って捨てられる」** — POST /client-invitations は client_display_name / ttl_days / scopes を全対応済みなのに email しか送っていなかった (S-B03 client_name と同型) | 死に入力 | IssueInput として全項目を実 API 配線 (DB 突合で scopes=["view"]/期限 14 日/表示名の保存を実証) |
| 2 | クライアント列が email のみ (契約の client_display_name 未使用) | 契約未活用 | 表示名 + メールの 2 行表示 (モック準拠) |
| 3 | 失効が確認なし即実行 | UX 破壊的操作 | 2 段階確認 (キャンセル/失効する) |
| 4 | ?project= 無しで行き止まり (WS 設定からの導線が該当) | 到達性 | useProjectId フォールバック (最後に開いたプロジェクト) |
| 5 | モックの「使用回数」列 | API不在 | 使用回数記録 API が無いため「使用日」(used_at 実データ) に置換。履歴の終了日も revoked_at 実データ化 (GAP-027) |
| 6 | モックの「再送」ボタン | API不在 | 再送 API 不在のため未描画 (Rule 10)。onResend prop も撤去 (GAP-027)。再発行は表示名引き継ぎで実装 |
