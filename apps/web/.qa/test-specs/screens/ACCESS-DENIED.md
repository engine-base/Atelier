# ACCESS-DENIED 権限がありません 画面別テスト仕様（/access-denied・GAP-219・human-grade-qa test-plan）

運営でない人が `/admin` 配下を開いたときに middleware が差し替える着地先。

**この画面の役目は「拒否を伝えること」ではなく「次にどうすればいいかを渡すこと」。**
以前は運営コンソールの枠を描いたうえで同じメッセージを 11 件・約 7 秒間出していた
（実測）。触れないメニューを見せ、同じ文言を浴びせ、次の手を言わない、が同時に
起きていた。
