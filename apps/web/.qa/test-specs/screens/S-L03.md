### UI (S-L03) 追加描画 — すべて実データ

- バナー「リンク有効期限：残り N 日」(招待の実 expires_at)、ヘッダカードに運営表示 + 工程進捗バー + 実 %。
- 成果物一覧 / モックギャラリー (全 N 画面)。内容プレビュー・DL はモックにも無く scope 外。
- 「あなたのコメント（N）」+ 運営返信 (bg 区別)、「コメントを投稿」フォーム (comment スコープ保有時のみ表示 — view-only では出さない)。
- content API の個別失敗は「取得できませんでした」の honest 表示 (本体ビューは維持・偽の空を出さない)。
