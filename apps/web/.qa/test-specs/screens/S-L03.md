| # | 欠陥 | 分類 | 是正 |

| 3 | 390px でスコープピルが縦折れ | レスポンシブ | whitespace-nowrap |
| 4 | モックの成果物一覧/フェーズ進捗バー/モックグリッド/コメント一覧/有効期限残日数 | API不在 | client-portal API は GET /client/projects/{id} (id/name/description/scopes/表示名) のみ。コンテンツ系はアクセス範囲カード等で honest 表示 (GAP-029) |
