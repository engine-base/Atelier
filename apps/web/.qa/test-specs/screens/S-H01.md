### GAP-024 是正（2026-08-10 — 「編集」+ バージョン操作）

> 監査スクリプト: `apps/web/.audit-h01-edit.mjs`（3 連続 ALL PASS・DB/storage 実体突合・再実行可能）。
> pytest: `tests/routes/test_mocks.py`（revise/duplicate/discard/R-T08 の 4 件追加、12 passed）。
> vitest: `tests/bundle-h/uc13-mock-viewer.test.tsx`（revise/503/ワンダ表示/複製/破棄 2 段階の 5 件追加、14 passed）。

**設計根拠**: 確定アーキ（`decision_log.json` / `docs/selected-libraries.md`）で、モック生成・反復は
Open Design（nexu-io/open-design, Apache-2.0）のパターン「自然言語指示 → agent が HTML を生成」を
デザイン領域に直接活用すると決定済み。Atelier での担当はデザイナー AI 社員ワンダであり、
S-H01 モック原文のバージョン author「ワンダ（更新）」はこのフローの表れ。
したがって「編集」は人間の HTML 手編集/再アップロードではなく、**ワンダへの修正依頼 →
LLM が全文 HTML を改訂 → 新バージョン生成**として実装した。
