### 検出・是正した欠陥

| # | 欠陥 | 分類 | 是正 |
|---|---|---|---|
| 1 | アプリ内に /mocks への導線がゼロ（S-N01/S-O01 と同型） | 到達不能画面 | プロジェクトナビに「モック」追加 + ?mock 無し時のモック一覧ピッカー実装 |
| 2 | モックのバージョン履歴パネルが未実装（GET /mocks/{id}/versions API は実在） | UI断線 | バージョンチェーン描画（表示中マーク・meta_tags.note・旧版リンク・「vN · 最新」ピル）を実 API 配線 |
| 3 | モックのコメントパネルが未実装（comments API は target_type=mock 対応済） | UI断線 | 一覧/追加(POST)/解決(PATCH status=resolved) を実 API 配線 |
| 4 | 修正依頼ボタン未実装 | UI断線 | /chat?project={project_id} への実リンクとして実装 |
| 5 | storage 503 で画面全面エラーになり、生きているメタ系 API まで見えなかった | 誤全面エラー | frame 領域のみ honest メッセージ、バージョン/コメントパネルは稼働継続 |
| 6 | 390px でデバイス切替ラベルが 1 文字ずつ縦折れ | レスポンシブ | whitespace-nowrap + overflow-x-auto（390px 実撮影で確認） |
| 7 | **POST 直後の read-your-own-write レース（API 全体構造バグ）**: yield 依存 teardown の commit がレスポンス送信後のため、201 直後の次リクエストが未コミット行を読めず POST /mocks → /versions が間欠 404 | データ整合 | `CommitBeforeResponseMiddleware` 追加（response.start 転送前に commit。SSE/4xx+ は除外）。回帰: `apps/api/tests/test_txn_commit.py` 5 件 + 監査スクリプト 3 連続 25/25 PASS で根絶実証 |
| 8 | モックの「編集」ボタン・バージョンパネル「…」メニュー | API不在 | 未描画（Rule 10）→ GAP-024 起票 |
