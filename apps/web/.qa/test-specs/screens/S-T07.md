# ST07 運営 既定デザインテンプレ 画面別テスト仕様（S-T07・GAP-159・human-grade-qa test-plan）

> 種別: admin studio / 結果列は空=planned。
> 備考の `ai_required` は実行場所の分離: `no`=この環境で消化する / `yes`=AI 実行基盤が要る（BLOCKED 可）。
> **意図**: 運営側が「**最初から入っている見た目の型**」を用意する。利用者はそれを継承し、
> 気に入らなければ上書きし、迷ったら既定に戻せる。運営が触るのは**全アカウントに効く**ので、
> ここは **権限の分離**（運営以外は入れない）と **継承の向き**（運営を直しても利用者の上書きを壊さない）が要。
