## design-audit ラウンド v2 (2026-07-19) — 死にボタン撤去 + コメント解決/状態配線

> モック: `06_mockups/output/S-G01-viewer.html` / 実装: `apps/web/app/outputs/s_g01/`
> 実操作: `.audit-g01.mjs` 9/9 PASS (コメントパイプ API end-to-end + honest 503 + 390px)
> ★ dev は storage backend 未設定 → content-url 503。ビューア本体 (iframe) は環境制約で
>   描画不能。画面は「保存先が未設定」を honest に表示 (偽の空ビューアを出さない)。
>   UI 配線は vitest (uc12 6 件) が担保。コメントパイプは本スクリプトが API で end-to-end 実証。

### モック要素台帳 (Rule 10 全分類)

| モック要素 | 分類 | 対応 |
|---|---|---|
| HTML プレビュー (iframe) | 実装 (storage 依存) | content-url の署名 URL を iframe。dev は 503 で honest メッセージ |
| 編集 ボタン | **撤去 (v2)** | 成果物編集 API 不在の disabled 死にボタンだった → 撤去 (GAP-023, Rule 10) |
| 原本 リンク | 実装 | content-url を新タブで開く |
| JSON/MD タブ・バージョン選択・DL | 静的クローム + GAP-023 | content-url は HTML のみ。偽の切替をしない旨を gap 化 |
| コメント一覧 | 実装 | GET /comments (target_type=workflow_output)。API で反映を実証 |
| コメント投稿 | 実装 | POST /comments (楽観追加)。201 + DB 永続を実証 |
| コメント未解決バッジ | **実装 (v2)** | status(open/resolved) を集計し「未解決 N / すべて解決済み」表示 (モック準拠) |
| コメント解決 | **実装 (v2)** | 「解決にする」→ PATCH /comments/{id} status=resolved → DB 突合 |
| 返信スレッド (親子) | **実装 (v2, 表示のみ)** | parent_comment_id を isReply でインデント表示。返信投稿 UI は GAP-023 |
| 作成者名 | 実装 (是正) | 生 UUID 直出しを撤去 → 「クライアント（招待）/メンバー xxxx/あなた」ラベル (鉄則5) |
| 座標ピン・AI 修正提案(承認/却下) | 撤去 + GAP-023 | 高度コメント API 未対応。偽 UI を置かない |
