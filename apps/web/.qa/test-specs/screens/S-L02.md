### 検出・是正した欠陥

| # | 欠陥 | 分類 | 是正 |
|---|---|---|---|
| 1 | **モックの同意 2 種 (規約/プライバシー/越境・機密保持) が丸ごと欠落** — 同意なしでサインインできた | 同意ゲート欠落 | 必須チェック 2 種を実装 (zod literal(true))。法務ページは実ルート /terms /privacy へリンク。未同意では送信されないことを DB 突合 (used_at null) で実証 |
| 2 | ボタン文言がモック乖離 (プロジェクトを開く) | モック乖離 | 「同意してサインイン」に統一 |
| 3 | モックの招待元/プロジェクト名/残り日数/招待先メールのプレビュー表示 | API不在 | トークンから署名前に招待メタを引くプレビュー API が無いため汎用文言で honest 表示 (GAP-028)。同意のサーバー永続も client 用 consents API 不在で UI ゲートのみ (GAP-028) |
