# S-A02 OAuth 完了 画面別テスト仕様（/auth/oauth-complete・GAP-020・human-grade-qa）

OAuth プロバイダのコールバック着地ページ。API の
`GET /auth/oauth/{provider}/callback` が成功時は
`#access_token=…&expires_at=…`（**フラグメント** — サーバーログ / Referer に
漏れない）、失敗時は `?error=access_denied|exchange_failed|account_inactive`
で 302 してくる。成功時は既存 signin と同一書式で cookie 格納 → /projects へ
`location.replace`（履歴にトークン付き URL を残さない）。失敗時は誠実に
エラーを出してサインインへ戻す。**偽の成功表示はしない。**

> この画面は実装済みなのに正本が無かった（丸ごと未検査）。2026-08-27 に
> 正本を新設し、既存 `tests/bundle-e/oauth.test.tsx`（9 passed）と実機で裏取り。
