## GAP-031④ 是正 (2026-08-04) — 「~/.claude/skills/ から再取込」の実装

> 監査スクリプト: `apps/web/.audit-t02-t06-import.mjs`（再実行可能・実操作+DB 突合・3 連続 ALL PASS）。
> pytest: `test_skills.py` に 3 件 (parser / upsert・dedupe・運用設定保持 / 403・409)。

モックの「~/.claude/skills/ から再取込」はローカル一括再取込 API 不在で未描画
だった。POST /admin/skills/reimport (admin gate) を新設して是正:

- サーバーの `ATELIER_SKILLS_DIR` (既定 `~/.claude/skills`) を走査し、
  `<skill>/SKILL.md` の YAML frontmatter (name/description) を解析して
  name キーで upsert。frontmatter 無しはディレクトリ名にフォールバック
- **新規=追加 / 内容変更=更新 / 同一=変更なし** に分類し summary を返す。
  **is_active・装着設定・version は上書きしない** (画面で行った運用設定を
  再取込で壊さない — 実操作監査で is_active=false 保持を実証)
- ディレクトリ不在は 409 の明示エラー。audit `skill.reimport` (summary)
- UI: 一括 write のため 2 段階確認 → 結果バナー (追加 X / 更新 Y / 変更なし Z)
