## SL02-207 期限切れ・失効の理由が日本語で分かる (shots/SL02-207-revoked-preview.png, SL02-207-revoked-submit.png)
  失効リンク (INV1B の raw token を /portal/signin?token=… で開く, 01:48:15):
    画面 role=alert「招待トークンが無効です。リンクをご確認ください。」(preview API 401 {"detail":"リンクが正しくないか、有効期限が切れています。"})
    同意 2 つを ON にして送信 → 同じ alert (signin API 401 同 detail)。入れない (URL は /portal/signin のまま)。
    本文テキストに UUID / "invitation_id" / "expired" / "revoked" は出ない。「トークン」という語は出る。
    **「招待トークン」入力欄に URL の raw token がそのまま表示される** (スクショで確認。証拠スクショは入力欄をマスクして再撮影)。
  期限切れリンク: 作成不可 (POST /client-invitations の ttl_days 最小 1 日、DB 直接操作の手段なし) → 未実走
判定: FAIL — 失効リンクは入れないが「理由が日本語で分かる」を満たさない: 画面は「無効」、API は「正しくないか、有効期限が切れています」と
  **失効を期限切れ扱い**で案内する (失効 API は invitation_revoked を持つのに signin/preview では invalid_token に畳まれる)。
  加えて「トークン」の語が画面に出る (行は token を内部識別子として列挙)。期限切れ側は BLOCKED (解除条件: 期限切れ招待を作れる手段 = ttl 秒指定 or staging DB 操作)。
